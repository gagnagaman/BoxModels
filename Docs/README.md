# Documentation

Readable and printable versions of the original Mathematica notebook
`Work.nb` (*"A review of a hierarchy of box models"*).

| File | Description |
|------|-------------|
| [`BoxModelNotes.html`](BoxModelNotes.html) | Self-contained HTML version: prose, input code, and all 30 figures rendered from the notebook's embedded PostScript. Opens in any web browser; no Mathematica required. |
| [`NotesForBoxModels.pdf`](NotesForBoxModels.pdf) | 43-page PDF print of the notebook, including prose, input cells, and figures. Some mathematical symbols appear as placeholders because fonts used by the original notebook were not available when it was printed. |
| [`Workfile.nb.pdf`](Workfile.nb.pdf) | 11-page A4 print produced by Mathematica 4.0 for X (March 2008). Covers the first part of the notebook, through the Rahmstorf stability analysis. |
| [`Workfile.nb.ps`](Workfile.nb.ps) | Complete 34-page PostScript print of the notebook (April 2000). |

The original `Work.nb` is kept locally and is not part of this repository.

For a plain-text-friendly rendering, start with `BoxModelNotes.html`. To
reproduce the figures and analysis in Python, see the scripts in the parent
directory and the main [`README.md`](../README.md).
